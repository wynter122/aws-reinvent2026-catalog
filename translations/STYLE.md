# 세션 번역 기준

re:Invent 세션의 제목과 설명을 한국어로 옮길 때 따르는 기준입니다. 읽는 사람은 AWS를 쓰는 한국 개발자와 엔지니어이고, 목적은 세션을 고르는 것입니다.

## 원칙

- 원문에 있는 내용만 옮깁니다. 요약하거나 덧붙이지 않습니다.
- 직역보다 한국 개발자가 실제로 쓰는 표현을 고릅니다.
- 한 파일 안에서, 그리고 파일끼리도 같은 용어는 같은 말로 옮깁니다. 아래 용어표를 따릅니다.

## 문체

- **제목**은 명사형으로 짧게 끝냅니다. 예: "Amazon Bedrock으로 분쟁 해결 자동화", "대규모 이벤트 라우팅: Amazon EventBridge 활용"
- **설명**은 "~합니다"체로 씁니다. "In this session, learn how to…"는 "이 세션에서는 …하는 방법을 알아봅니다"처럼 옮깁니다. 명령형 문장("Learn…", "Discover…", "Join us…")도 "~합니다/~봅니다"로 바꿉니다.
- 괄호 속 후원 표기는 "(sponsored by NVIDIA)" → "(NVIDIA 후원)"으로 옮깁니다.

## 원문 그대로 두는 것

- AWS·Amazon 서비스와 기능 이름: Amazon Bedrock, AWS Lambda, Amazon Q Developer, Amazon SageMaker AI, AgentCore, Kiro 등
- 회사, 제품, 오픈소스 이름: NVIDIA, Netflix, Kubernetes, Karpenter, Terraform, PyTorch 등
- 사람 이름
- 약어: LLM, RAG, API, SLA, CI/CD, MCP, IaC, GPU 등
- 코드, 명령어, 파일 이름, 숫자, 단위, URL

제목이 "AWS Technical Essentials"처럼 이름뿐이라 옮길 말이 없으면 원문을 그대로 둡니다. 한글을 넣으려고 원문에 없는 말을 덧붙이지 않습니다.

조사는 원문 이름 뒤에 자연스럽게 붙입니다. 예: "Amazon Bedrock으로", "AWS Lambda를"
